# Privacy Policy: Player Linker for Fantrax

_Last updated: November 10, 2026_

Player Linker for Fantrax is a Chrome extension that adds links to Fangraphs, Baseball Savant, Baseball-Reference and Prospect Savant next to player names on fantrax.com pages.

## What the extension collects

Nothing. The extension does not collect, store, sell or share any personal information, browsing history, login details, league data or anything else about you.

## What the extension does

- **On fantrax.com pages**, it reads player names and player IDs that are already on the page, only so it can place the right links next to them. This happens entirely inside your browser and nothing is sent anywhere.
- **Every 6 hours**, it downloads a public list of baseball player IDs (`data/player_map.csv`) from this project's GitHub repository. That request sends no information about you. GitHub may log the request like any website visit; see GitHub's privacy statement.
- **It saves that player list** in Chrome's local extension storage on your computer, so the links work without downloading it on every page.

## Third parties

When you click one of the links, you go to Fangraphs, Baseball Savant, Baseball-Reference or Prospect Savant, and their own privacy policies apply there.
